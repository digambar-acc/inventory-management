📋 System Overview

A comprehensive factory inventory management system with real-time tracking, demand forecasting, order management, and financial analytics. Built with modern web technologies for a responsive, internationalized user experience.

Key Features: Multi-language support (EN/JA), Global filtering system, Real-time dashboard, Demand forecasting, Backlog tracking, Financial reporting, Task management

🔄 Data Flow

1. User Interaction
User selects filters in FilterBar or navigates to a view
2. State Update
Composable (useFilters) updates reactive state
3. Component Watch
View component watches filter changes and triggers data load
4. API Request
api.js builds request with URLSearchParams, sends to backend
5. Backend Processing
FastAPI receives params, applies filters, validates with Pydantic
6. Data Filtering
Apply warehouse → category → status → month filters sequentially
7. Response
Return filtered List[Model] as JSON
8. UI Update
Component receives data, computed properties recalculate, Vue re-renders

🎯 Global Filter System

4 Global Filters:
  • Time Period: Month (2025-01 to 2025-12) or Quarter (Q1-2025, etc.) or "all"
  • Location: San Francisco, London, Tokyo, or "all"
  • Category: Circuit Boards, Sensors, Actuators, Controllers, Power Supplies, or "all"
  • Order Status: Delivered, Shipped, Processing, Backordered, or "all"

🎨 Key Architectural Patterns

Vue 3 Composition API

setup() {
  // Reactive state
  const items = ref([])
  const loading = ref(false)

  // Computed (derived, cached)
  const filtered = computed(() =>
    items.value.filter(...)
  )

  // Methods
  const loadData = async () => { ... }

  // Lifecycle
  onMounted(loadData)

  // Watch for changes
  watch(filters, loadData)

  return { items, loading, filtered, loadData }
}

Global State with Composables

// composables/useFilters.js
const selectedPeriod = ref('all')  // Shared across app
const selectedLocation = ref('all')

export function useFilters() {
  const getCurrentFilters = () => ({
    month: selectedPeriod.value,
    warehouse: selectedLocation.value,
    // ...
  })

  return { selectedPeriod, selectedLocation, getCurrentFilters }
}

Centralized API Client

// api.js
const API_BASE = 'http://localhost:8001/api'

export const api = {
  async getOrders(filters) {
    const params = new URLSearchParams()
    if (filters.warehouse !== 'all') {
      params.append('warehouse', filters.warehouse)
    }
    const response = await axios.get(`${API_BASE}/orders?${params}`)
    return response.data
  }
}

📊 Data Models

Key Pydantic Models:
  • InventoryItem: SKU, name, category, warehouse, quantity, reorder point, unit cost, location
  • Order: Order number, customer, items list, status, dates, total value, warehouse, category
  • DemandForecast: Item SKU, current demand, forecasted demand, trend, period
  • BacklogItem: Order ID, item SKU, quantity needed/available, days delayed, priority
  • PurchaseOrder: Backlog item ID, supplier, quantity, cost, delivery date, status
